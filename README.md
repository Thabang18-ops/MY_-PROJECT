# VitaPura Website

## Project Overview

VitaPura is a wellness and lifestyle website designed to provide users with information about wellness services, products, and health-focused resources.

The website was developed as part of the WED5020 Web Development portfolio of evidence (POE).

## Purpose

The purpose of the VitaPura website is to create a user-friendly online platform that presents wellness-related information and services in a clear and accessible way.

The website allows users to:

- View information about VitaPura
- Explore available products
- Explore wellness services
- Submit enquiries
- Access contact information
- Navigate between different sections of the website

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Git
- GitHub

## Website Pages

The website contains the following main pages:

- `index.html` – Home page
- `about _us.html` – About VitaPura
- `services.html` – Wellness services
- `product.html` – Products
- `enquiry.html` – Enquiry form
- `contact.html` – Contact information
